Two roles. One shared space.

Architect

Furniture builders

Regular subagents. Parallel Blender builds from photos and editable starter scripts.

Editable apartment + user briefScene JSON · Assets · Evidence · Needs · Drafts
↓

Designer

Explores layouts, keeps belongings and storage needs, checks fit and budget.

↔

Design subagents + references

Distinct design options. Pinterest or screenshots, plus real catalog products.

↓
Checked, priced proposals→User edits / accepts

Accepted changes update the shared scene. Both agents can be steered live.

Capture only when needed

Plan-only supports unbuilt apartments. For existing rooms, the architect guides photo positions. Any builder can request evidence; requests are combined, other work continues.

Keep control and fidelity

Ask, measure or mark an estimate. Recreate the actual furniture. Proposals need approval; new asset detail preserves newer manual placement edits.

02 / Tools

A small agent toolkit.

  • Codex SDK + regular subagentsPersistent work, async builds and live steering.
  • Scripts + mistake-based skillsBlender, renders, scene edits, checks and prices. Skills encode lessons from actual failures.
  • Scene JSON + web appStable IDs, sizes, attachments, evidence and catalog links. 3D/plan editor, chat and photo requests.
03 / Evals

Prove it on unseen rooms.

  • Furniture likenessKnown dimensions and held-back photo angles. Blind human votes: with vs without starter scripts.
  • Room and layout checksCode checks geometry, collisions, access, storage and budget. Humans judge likeness and design.
  • Cost of getting it rightTrack time, token use and corrections. Failures become tests and skill updates; keep unseen test cases.
